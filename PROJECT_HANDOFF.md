# Project handoff: Empty Folder Radar

## One-line description

A small Windows utility that finds empty folder branches and moves selected ones to the Recycle Bin after review.

## Positioning

Large cleanup suites prove that empty-folder removal is a real task. Empty Folder Radar offers only that task, with a clearer preview and conservative deletion rules.

## Demo flow

1. Show a messy project/export directory with several abandoned empty folders.
2. Drag the parent folder into Empty Folder Radar.
3. Show direct empty folders and collapsed empty trees.
4. Uncheck one folder that should be kept.
5. Move the rest to the Recycle Bin and show that restoration remains possible.
